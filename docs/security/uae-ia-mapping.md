# UAE Information Assurance control mapping (GOV-6)

Evidence for customers' security reviews: how Zelvo supports the control families of the **UAE Information Assurance Regulation** (TDRA; formerly the UAE IA Standard). It maps families and the main areas within them; control numbers differ between editions, so reviewers should check each line against the edition their entity applies. Last reviewed with task L1 (Phase 2 release readiness, 2026-11-28).

**Responsibility**: **Zelvo** (the product provides the control), **Shared** (the product provides the means, the customer sets it up or runs it), **Customer** (the customer's organisation, hosting or processes; Zelvo is self-hosted, GOV-4).

| --- | --- | --- | --- | --- |
